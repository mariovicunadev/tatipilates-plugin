# Documentacion

Indice de documentacion operativa y tecnica del plugin Tati Pilates.

## Trabajo con Codex

- `codex-workflow-guide.md`: guia para abrir nuevos chats, pedir cambios y cerrar tandas.
- `codex-workflow-guide.pdf`: version PDF de la guia.

## Releases y updates

- `release-runbook.md`: pasos para cerrar una tanda, publicar a staging y promover a live.
- `updater-workflow.md`: detalle del updater privado por canales `staging` y `stable`.
- `testing-checklist.md`: pruebas antes de publicar una version.
- `troubleshooting.md`: diagnostico de problemas frecuentes.

## Arquitectura y datos

- `architecture.md`: mapa de clases, capas y responsabilidades.
- `data-model.md`: tablas, relaciones, indices y reglas de datos.
- `local-development.md`: entorno local, LocalWP, symlink, PHP y datos demo.

## Producto y seguridad

- `product-decisions.md`: decisiones funcionales que deben respetarse.
- `security-checklist.md`: checklist de seguridad para cambios sensibles.
- `roadmap.md`: mejoras futuras y deuda tecnica.

## Reglas

- No documentar credenciales reales.
- No pegar tokens.
- Mantener `CONTEXTO.md` fuera de Git.
- Actualizar `CHANGELOG.md` cuando una tanda cambia comportamiento.
- Actualizar estos docs cuando cambie el workflow.
